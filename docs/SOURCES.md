## Ограничения метода

- Из песочницы недоступны некоторые первоисточники (blogs.windows.com, news.microsoft.com — 403); их содержание подтверждено поисковым индексом и рефами — помечено в строках выше.
- Часть фактов верифицирована на уровне датированных заголовков новостных индексов (отмечено «заголовок»): для датированных новостей этого достаточно для даты и сути, дословные формулировки не цитируются.
- Оценки бюджетов ($100M/$200M/$300M/$1,5–1,8B) — всегда заявления прессы, не официальные цифры Microsoft.
