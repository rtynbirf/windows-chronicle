# 01. Хронология: 1983–2026, десять эпох

> Даты релизов сверены со справочными источниками (Microsoft Lifecycle, список версий Wikipedia) и с публикациями 2024–2026 гг. Спорные даты помечены.

## Эпоха 0. Предыстория (1981–1985)

В 1981 году Билл Гейтс и Стив Балмер посещают Xerox PARC; Microsoft покупает лицензию на 86-DOS (QDOS), превращая её в MS-DOS для IBM PC. В **ноябре 1983** Microsoft анонсирует «Interface Manager», который к выходу переименован в Windows. Первая «обещанная» дата (конец 1984) сорвана — Windows отстаёт от Lisa и Macintosh, зато работает на дешёвом IBM-совместимом железе. Историческая рамка всей эпохи: **Windows — графическая оболочка поверх MS-DOS**, а не отдельная ОС.

## Эпоха 1. DOS-оболочки (1985–1993)

- **20.11.1985 — Windows 1.01**: плиточные окна, MS-DOS Executive, Calculator, Notepad, Paint (тогда «Windows Paint»), часы, буфер обмена. Мышь — экзотика.
- **09.12.1987 — Windows 2.03**: перекрывающиеся окна, меню File/Edit/Window/Help, Excel и Word для Windows — переломная точка для ISV-экосистемы. В 1988 Apple подаёт знаменитый иск «о внешнем виде» — Microsoft выигрывает в 1994.
- **27.05.1988 — Windows/286 и Windows/386**: 386-версия запускает несколько DOS-приложений в окнах (виртуальный 8086).
- **22.05.1990 — Windows 3.0**: Program Manager, File Manager, protected mode, ≈10 млн копий — первый массовый хит.
- **06.04.1992 — Windows 3.1**: TrueType, OLE, «386 enhanced mode» по умолчанию; 3 млн копий за два месяца.
- **Сеть:** Windows for Workgroups 3.1 (10.1992) и 3.11 (08.1993) со встроенным SMB и 32-битным TCP/IP — зарождение корпоративного сетевого стека.

**Контекст эпохи:** память измерялась килобайтами, multitasking — кооперативным, стабильность — лотереей. Формируются две вечные боли: конфликты памяти (640 КБ conventional) и отсутствие стандартов драйверов.

## Эпоха 2. Рождение NT (1993–1995)

- **27.07.1993 — Windows NT 3.1** (Workstation и Advanced Server): команда Дэйва Катлера (из DEC), переносимое гибридное ядро, Win32 API, NTFS, вытесняющая многозадачность. Знаковая развилка: параллельно существуют «домашняя» DOS-линейка и «взрослая» NT.
- **21.09.1994 — NT 3.5**, **30.05.1995 — NT 3.51**: скорость, TCP/IP по умолчанию; NT становится серверной ставкой корпорации.

## Эпоха 3. Взрыв массового рынка — линейка 9x (1995–2000)

- **24.08.1995 — Windows 95**: Start-меню, панель задач, Проводник, Plug and Play, длинные имена файлов. Полуночные очереди, запуск с Rolling Stones «Start Me Up», рекламный бюджет ≈ $300 млн. OSR2 (08.1996) приносит FAT32.
- **24.08.1996 — Windows NT 4.0**: интерфейс 95 в NT, IIS — фундамент корпоративного веб-сервера; Terminal Server Edition — 1999.
- **25.06.1998 — Windows 98**: USB, интеграция IE (файл для антимонопольного процесса США), FAT32 в рознице; **05.05.1999 — 98 SE** (спор дат: ряд справочников указывает 10.06.1999).
- **14.09.2000 — Windows Me**: последняя 9x; System Restore, Windows Movie Maker — и репутация самой глючной версии (в 2006 PC World назвал её 4-й в списке худших технопродуктов).

**Контекст эпохи:** интернет вытаскивает Windows из домашних ПК в сеть; антимонопольное дело США (файл 18.05.1998, решение 2000: разделение компании отменено апелляцией 2001) стартует из-за связки IE+Windows.

## Эпоха 4. Консолидация на NT (2000–2006)

- **17.02.2000 — Windows 2000** (Pro/Server/Advanced/Datacenter): Active Directory, NTFS 3.0, EFS.
- **25.10.2001 — Windows XP**: слияние двух линеек в одну NT-платформу; интерфейс Luna, активация (антипиратство), брандмауэр, удалённый рабочий стол. SP1 (09.2002), **SP2 (08.2004)** — Security Center, включённый брандмауэр, переработанный стек безопасности после меморандума Trustworthy Computing (январь 2002), SP3 (05.2008). XP Professional x64 — 25.04.2005.
- **24.04.2003 — Windows Server 2003** (R2 — 06.12.2005): IIS 6, зрелость AD.

**Контекст эпохи:** XP живёт 12,5 лет поддержки (до 08.04.2014) и становится «вечной» ОС — что породит будущую боль миграции. Волны червей: ILOVEYOU (2000), CodeRed/Nimda (2001), Blaster (2003), Sasser (2004), Conficker (2008).

## Эпоха 5. Перестройка и «перезагрузка» (2006–2012)

- **08.11.2006 — Vista RTM**; бизнес-релиз 30.11.2006, потребительский **30.01.2007**: Aero, UAC, WDDM-драйверная модель, BitLocker, поиск. Тяжёлый старт из-за драйверов и требований; SP1 (02.2008) и SP2 (04.2009) лечат производительность.
- **27.02.2008 — Windows Server 2008**: Hyper-V; **R2 (22.10.2009)** — только x64.
- **22.10.2009 — Windows 7**: Superbar, библиотеки, Jump Lists, Direct2D/DirectWrite, XP Mode; SP1 (22.02.2011). Реабилитация бренда; >630 млн лицензий.
- **21.07.2007 — Windows Home Server** (по MS Lifecycle; часть справочников — ноябрь 2007): Drive Extender, домашние бэкапы.

## Эпоха 6. Сенсорные метания (2012–2015)

- **04.09.2012 — Windows Server 2012**; **26.10.2012 — Windows 8**: Metro/Start screen, Charms, Store, WinRT/UWP — попытка перепрыгнуть в планшетную эру на фоне iPad. Кнопка Пуск удалена; 8.1 (**17.10.2013**) возвращает её, Update (04.2014) возвращает приложениям «крестик». Windows RT для ARM не даёт запускать x86-софт.
- **18.10.2013 — Server 2012 R2**.
- Итог эпохи: самая резкая негативная реакция на смену UX в истории платформы; «Пуск» возвращает Third-party Start8/Classic Shell.

## Эпоха 7. Windows as a Service (2015–2021)

- **29.07.2015 — Windows 10**: бесплатный год обновлений, GWX-кампания, «последняя версия Windows» (формулировка Джерри Никсона, Ignite 2015), полугодовые feature updates (Threshold 1/2, Redstone 1–5, 19H1/H2, 20H1/H2, 21H1/H2), Edge (изначально EdgeHTML), DirectX 12, WSL (2016), «1 млрд устройств» к марту 2020.
- Серверы: **Server 2016 (12.10.2016)** — контейнеры, Shielded VMs, неудачный поворот к Nano Server; **Server 2019 (GA 13.11.2018, Ignite)**; **Server 2022 (18.08.2021)**.
- **Смерть мобильной Windows:** Windows Phone 7 (10–11.2010) → WP8 (29.10.2012, NT-ядро, разрыв совместимости) → WP8.1 (14.04.2014) → Windows 10 Mobile (11.2015); финальная ветка 1709 (2017), поддержка — до 14.01.2020. «Application gap» добивает платформу; покупки Nokia обесцениваются (списания ≈ $7,6 млрд, 2015–2016).
- **18.10.2022 — Windows 10 22H2**: последняя версия; EOS **14.10.2025**.

## Эпоха 8. Windows 11 и стена безопасности (2021–2024)

- **24.06.2021 — анонс**, **04–05.10.2021 — Windows 11 21H2 (Sun Valley)**: центрированный Пуск, Snap Layouts, Widgets, Teams; обязательные **TPM 2.0, Secure Boot** и список CPU (Intel 8-го поколения+, AMD Zen+) — под отсечение попали сотни миллионов полностью работоспособных ПК (оценки аналитиков — 400–600 млн устройств на пике проблемы).
- **20.09.2022 — 22H2 (Sun Valley 2)**: вкладки в Проводнике; **31.10.2023 — 23H2** (первый enablement-пакет); Copilot-превью — 26.09.2023.
- Возврат «never combine» на панели задач — только в обновлении ноября 2023; подсистема Android (WSA) объявлена в 2021, депрекирована в марте 2024 (закрыта в 2025).

## Эпоха 9. AI PC и уход Windows 10 (2024–2026)

- **20.05.2024 — анонс Copilot+ PC**: NPU ≥ 40 TOPS, первая волна на Snapdragon X Elite/Plus (июнь 2024), затем AMD/Intel. Купившие ранее «AI PC» без NPU остались за бортом новых функций. **Recall** (ежесекундные скриншоты) вызывает бурю по приватности уже в день анонса: в июне 2024 фича сделана opt-in с Windows Hello, релиз перенесён (по сообщению The Verge от 01.11.2024 — на декабрь 2024).
- **01.10.2024 — Windows 11 24H2 (Germanium)**: новый servicing branch, checkpoint-обновления; каскад блокировок установки (сканеры, AU-устройства) и волна багов: BSOD в играх с Easy Anti-Cheat, «мусор» с USB-принтеров (январь 2025), замедление SSD/HDD (февраль 2025), сбои NVMe на больших записях в KB5063878 (август 2025).
- **01.11.2024 — Windows Server 2025** (LTSC, база 24H2, hotpatching — GA 2025).
- **30.09.2025 — Windows 11 25H2** (enablement KB5054156): новый одностраничный Пуск (Recommended → Recent), Copilot Vision; октябрьский патч 2025 ломает USB-мышь/клавиатуру в WinRE — экстренный фикс.
- **14.10.2025 — конец поддержки Windows 10**: полноэкранные предупреждения, потребительский ESU до **12.10.2027** — 25.06.2026 Microsoft тихо продлила программу на второй год (бесплатно при 1000 баллов Rewards или включённой синхронизации Windows Backup, либо $30); корпоративный ESU до 2028. В августе 2025 подан иск с требованием продолжить бесплатные обновления.
- **Начало 2026 — Windows 11 официально пересекает 1 млрд пользователей** (выступление Наделлы; за 1576 дней). StatCounter: декабрь 2025 — 50,7 % у Win11; январь 2026 — 62,4 %; **февраль 2026 — 72,8 %** (Win10 — 26,3 %, Win7 — менее 1 %).
- **29.09.2026 — Windows 11 26H2** (enablement, «Windows 11 2026 Update»): включены по умолчанию **Administrator protection** (админ-права выдаются на время задачи, off by default), **встроенный Sysmon**, настройки-бэкап, app-specific действия панели задач, улучшения Проводника. Модель «continuous innovation»: ежемесячные инновации + годовой enablement.
- **Фон 2026:** несколько внеплановых экстренных патчей за год; Блокнот массово не запускался из-за сбоев серверного лицензионного сервиса (весна 2026) — симптом растущей облачной зависимости ОС; реклама в меню «Пуск» доведена до всех пользователей (PCMag).

## Горизонт

Официальная модель: «Windows больше не «большая версия раз в 3 года», а непрерывный поток + ежегодный enablement». Реальность: ежегодные «больш-версии» (24H2 → 25H2 → 26H2) по факту вернулись под другим именем. Открытые вопросы: дальнейшая ARM-экспансия (Snapdragon X2), судьба локальных учётных записей (bypassnro удалён в 2025), судьба классической Control Panel и глубина AI-интеграции. Справочники (Wikipedia, октябрь 2026) параллельно с 26H2 фиксируют ветку **26H1** (build-серия 28000) — первая H1-ветка с 21H1/H2 (2021); дата её GA в открытых источниках однозначно не указана — помечено как требующее проверки.
