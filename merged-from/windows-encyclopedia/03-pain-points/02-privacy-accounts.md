# Категория 2: Приватность, телеметрия, учётные записи (2015–2026)

## 2.1 Телеметрия Windows 10 (2015–)

- Windows 10 впервые массово собирает диагностику «по умолчанию»; уровни
  Basic/Full; в системных настройках сбор можно только ограничить, а не
  выключить — форумное и профессиональное мнение совпадает (r/sysadmin:
  «not currently possible… only to limit»).
- Ответы Microsoft: переработанный экран приватности при установке
  (Creators Update 2017), Diagnostic Data Viewer, страница «диагностических данных».
- Народные ответвления: O&O ShutUp10++, скрипты-«debloat» (Spcky/ChrisTitus) —
  полуторамиллионная аудитория средств «выключить телеметрию».

## 2.2 Обязательная учётная запись Microsoft (2021–2026)

- Windows 11 Home требует MSA при первом включении (июль 2021, osnews) [S16].
- Классические обходы: отсоединить сеть, `oobe\bypassnro`, `start ms-cxh:localonly`
  — Microsoft последовательно закрывает их в новых сборках; требования
  распространяются на Pro; локальная учётка остаётся после установки
  (замена на локальную возможна), но Setup требует онлайн.
- Побочный эффект: принудительная привязка к OneDrive/Backing-up-нотификациям
  («Action advised — back up your PC», 2025) [S17-блок Q&A].

## 2.3 Recall и «ИИ смотрит на ваш экран» (2024–)

- Copilot+ функция Recall: периодические скриншоты всего экрана с локальным
  поиском; май 2024 — анонс; шквал критики приватности (все, кто имел доступ
  к машине, могут увидеть историю); **13.06.2024** — отложена до декабря 2024
  (Insiders), релиз только после доработок безопасности [S18].
- Copilot Vision (GA 16.10.2025): ИИ видит экран по запросу — та же категория
  опасений, уже в продакшене [S27].

## 2.4 Рекламные уведомления и «советы»

- Всплывающие «рекомендации» (Edge, OneDrive, Game Pass) через Центр
  уведомлений; Microsoft Q&A (февраль 2026): «как отключить рекламу
  в правом нижнем углу» — официальный ответ: переключатели в Настройках [S17].
- Промо-уведомления браузера/бэкапа: категория «ads-as-system-notifications»
  с 2021 года.
