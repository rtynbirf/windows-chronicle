# Категория 1: Обновления и обслуживание (2015–2026)

Самая громкая современная категория: с переходом на Windows as a Service
обновления стали постоянным фактором жизни пользователя.

## 1.1 Принудительный апгрейд до Windows 10 (GWX, 2015–2016)

- «Get Windows 10» (GWX) — обязательное «рекомендованное» обновление.
- Октябрь 2015: экран с обратным отсчётом «Starting the upgrade in 60:00» —
  без опции отказа; Microsoft признала принудительный запуск «ошибкой» [S12].
- Июнь 2016: пресса описывает тактику как «malware-style»; Microsoft
  меняет курс [S12].
- Июль 2016: классовые иски в США и Израиле [S13]. Август 2017: после
  судебного дела Microsoft обещает не скачивать файлы апгрейда без явного
  согласия [S14].
- Народные инструменты: GWX Control Panel, Never10 — блокировщики апгрейда.

## 1.2 Обновления-разрушители

- **04.10.2018 — 1809 удаляет пользовательские файлы**: баг Known Folder Move;
  Microsoft отзывает обновление [S15].
- **Ноябрь 2018 — KB4048952**: массовая порча драйверов принтеров HP после
  патча (типичный кейс «патч ломает периферию»).
- **2024 — 24H2**: блокировка установки на устройствах Asus (нужен BIOS-фикс),
  сбои на HDD >8 ТБ, BSOD-эпизоды; Microsoft держит блок-лист [S8].
- **2025–2026**: ООБ-патчи 24H2 (14.09.2026) и фиксы 25H2 (28.10.2026) [S8] —
  поток «known issues» постоянен.

## 1.3 Перезагрузки «в худший момент»

- Классика: «Работа с обновлениями, не выключайте компьютер» на середине
  презентации/игры. Ответ Microsoft: Active Hours, restart required-окно
  с выбором времени — но принудительная перезагрузка при «pend» всё равно случается.

## 1.4 Экономика обновлений (2025–2027)

- Windows 10 EOL 14.10.2025 [S3]; consumer-ESU до 12.10.2027 — бесплатно
  при синхронизации с аккаунтом Microsoft (или за баллы/100 $) [S5], [S7].
- Коммерческий ESU: 61 $ → 122 $ → 244 $ за год, кумулятивно; с октября 2026
  вступление стоит уже 183 $ за два года [S6]. The Register: «цена остаться
  на Windows 10 с октября 2026 удваивается» [S11].
- Июнь 2026: истечение сертификатов Secure Boot 2011 года — необновлённые
  машины рискуют проблемами загрузки; обновления сертификатов идут через ESU [S6].

## 1.5 Service-паузы и «End of updates»

- 24H2 Home/Pro достигли «End of updates» 13.10.2026 [S8] — пользователи
  обязаны переезжать на 25H2/26H2, чтобы продолжать получать патчи.
