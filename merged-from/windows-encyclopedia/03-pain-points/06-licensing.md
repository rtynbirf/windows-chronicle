# Категория 6: Лицензирование и активация (2004–2026)

## 6.1 WGA и «у тебя пиратка» (2004–2010)

- Windows Genuine Advantage: обязательная проверка подлинности через
  Windows Update; 07.07.2006 — жалобы на ложную маркировку легальных копий
  XP как нелицензионных [S22].
- 04.05.2006: Microsoft подаёт иски против продавцов «серых» копий [S22];
  06.08.2006: общественная буря, два иска против самой Microsoft [S22];
  10.02.2010: суд отклоняет иск пользователей [S22].
- WGA Notifications «звонила домой» — прообраз будущей телеметрии по
  ощущениям пользователей.

## 6.2 Бесплатный год Windows 10 и его границы (2015–2016)

- Бесплатный апгрейд для 7/8.1 — до 29.07.2016 [S33]; после — платно (119 $ за Home).
- Отдельная линия: «бесплатный апгрейд с пиратских копий» — анонс января
  2015, откат в мае 2015 (Myerson: пираткам бесплатно нельзя) [S34-контекст].

## 6.3 Активация Windows 11 и аккаунтная привязка (2021–2026)

- Цифровая лицензия привязана к учётной записи Microsoft — смена железа
  без MSA стала болью; активация по телефону как атавизм живёт.
- Требование MSA при установке Home (2021+) усиливает ощущение
  «лицензия = аккаунт» [S16].

## 6.4 Подписочная экономика (2025–2027)

- Consumer-ESU Windows 10: бесплатно — при синхронизации ПК с MSA
  (или баллы Rewards/100 $) [S5], [S7]: безопасность в обмен на аккаунт.
- Коммерческий ESU: 61/122/244 $ кумулятивно [S6]; The Register: «цена
  остаться на Windows 10 удваивается с октября 2026» [S11].
- Microsoft 365/AI-подписки проталкиваются в родные приложения
  (Copilot Pro-промо в Пуске/уведомлениях) — слияние лицензирования с рекламой (категория 7).
