# Эпоха 5: 2015–2021 — Windows 10 и «Windows as a Service»

Верифицировано 31.10.2026. Источники: [S3], [S5], [S6], [S7], [S12]–[S18], [S24], [S33], [S34], [S39], [S40].

## Вехи

- **21.01.2015 — Windows 10 «delivered as a service»**: официальный анонс
  news.microsoft.com: Windows 10 «will be delivered as a service» [S24].
  Wikipedia: Windows 10 позиционировалась как «последняя версия Windows» —
  переход к SaaS-модели [S34]; Terry Myerson — о смене традиционного
  10-летнего цикла поддержки [S34].
- **29.07.2015 — релиз Windows 10** [S2]; бесплатный апгрейд для Windows 7/8.1
  в первый год — до **29.07.2016** [S33]; к маю 2016 — 300 млн устройств [S33].
- **Октябрь 2015 — скандал GWX**: принудительная установка апгрейда «Get
  Windows 10» с 60-минутным обратным отсчётом «Starting the upgrade in»,
  без опции отказа; Microsoft признала это «ошибкой» (VentureBeat via ghacks) [S12].
- **29.07.2016 — классовые иски** (США + Израиль) по практике апгрейдов [S13];
  июнь 2016 — пресса называет тактику «malware-style» [S12]; август 2017 —
  после судебного дела Microsoft обещает «никогда больше не скачивать файлы
  апгрейда без согласия» [S14].
- **04.10.2018 — версия 1809 удаляет файлы пользователей**: баг Known Folder
  Move стирает содержимое «Документов/Фото»; Microsoft отзывает обновление
  и ставит развёртывание на паузу [S15].
- **Май 2017 — WannaCry** (эпоха XP/7): 12.05.2017 атака шифровальщика через
  EternalBlue/SMBv1; NHS госпитали остановлены; Avast — >75 000 атак в 99
  странах в первый день; Kaspersky — >300 000 машин в 150 странах [S23].

## С чем боролись пользователи (эпоха 5)

- **Принудительные обновления и апгрейды**: GWX-надоедание, отсчёт 60 минут [S12];
  обновления ставились сами, перезагрузка «в худший момент»; активные часы
  появились как ответ на бунт.
- **Телеметрия**: Windows 10 впервые массово «телефонит домой»; в настройках
  сбор данных можно только ограничить, не выключить; инструменты вроде
  O&O ShutUp10 становятся народным стандартом; Microsoft позже даст
  Diagnostic Data Viewer.
- **1809: удаление файлов** обновлением — верх предательства доверия [S15].
- **Bloatware**: предустановленная Candy Crush, Xbox, «советы» с рекламой
  в меню Пуск.
- **Кортана/Bing**: поиск в Пуске нельзя было выключить полностью; Bing
  вписан в поиск системы.
- **Драйверы и обновления**: после кумулятивных патчей регулярно ломались
  принтеры и звук (кейс KB4048952, ноябрь 2018).
- **EOL-нависание**: «ваша версия больше не поддерживается» — 7 ушла 14.01.2020,
  10 ушла 14.10.2025 [S3], [S4].

## Что продвигала Microsoft (эпоха 5)

- **Windows as a Service**: «всегда актуальная, всегда защищённая» система [S24];
  бесплатные полугодовые Feature Updates вместо покупки новых версий.
- **Бесплатный апгрейд** (год) — самая большая «раздача» в истории ОС [S33].
- **Universal Windows Platform**: один магазин, одно приложение для всех экранов.
- **Cortana, Hello (биометрия), Edge** (как замена IE), **DirectX 12** —
  «гейминг нового уровня».
- **WSL — Windows Subsystem for Linux**: анонс на Build 30.03.2016,
  «Bash on Ubuntu on Windows» [S28]; в Anniversary Update (02.08.2016) [S28];
  WSLg на Build 2021; позже WSL open-sourced [S28] — переворот: «Linux —
  гражданин первой категории в Windows».
