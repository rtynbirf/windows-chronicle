# Полная систематизация Microsoft Windows (1985–2026)

Приватный исследовательский репозиторий: хронология всех версий Windows за 41 год,
категоризация болей пользователей за всё время существования системы и того,
в чём Microsoft активно её продвигала.

**Дата среза информации: 31.10.2026.** Режим антигаллюцинации: каждый факт,
дата и URL проверены веб-верификацией ДО записи в файлы (журнал —
[`06-sources/verification-journal.md`](06-sources/verification-journal.md)).
Эвристические оценки (рейтинг релевантности) явно помечены как эвристика.

## Методология

1. **Верификация**: каждая дата/событие — из открытых источников, проверенных
   31.10.2026 (официальные страницы Microsoft: support.microsoft.com,
   learn.microsoft.com, news.microsoft.com, blogs.microsoft.com; Wikipedia;
   профильная пресса: The Register, ZDNet, ExtremeTech, ghacks, Windows Central,
   SiliconANGLE). Полный журнал с URL — в `06-sources/`.
2. **Категоризация**: боли пользователей сгруппированы в 8 категорий
   (обновления; приватность/аккаунты; стабильность/драйверы; безопасность/малварь;
   смена интерфейса; лицензирование; реклама/bloatware; удаление функций/наследие).
3. **Рейтинг релевантности** в списке «двух полюсов» — **эвристика**:
   оценка по четырём критериям (длительность проблемы в годах, доля затронутых
   пользователей, тяжесть последствий, объём документированных жалоб/исков).
   Формулы нет — это экспертная сортировка, помечена явно.

## Ключевые verified-факты среза 31.10.2026

- Windows существует **41 год**: от Windows 1.0 (RTM 20.11.1985) до Windows 11 26H2 (GA 29.09.2026).
- Текущая версия: **Windows 11 26H2** (26300.9818, обновление 2026-10-28).
- Windows 10: поддержка прекращена **14.10.2025**; consumer-ESU продлён до **12.10.2027**
  (бесплатно при синхронизации с учётной записью Microsoft); коммерческий ESU — до октября 2028.
- Доля на десктопах (Statcounter, сентябрь 2026): **Win11 — 71,44 %, Win10 — 27,83 %**.
- Нынешний приоритет Microsoft: безопасность (меморандум Наделлы 03.05.2024
  «Prioritizing security above all else») и ИИ (Copilot+ PC, Copilot Vision GA 16.10.2025).
