# MERGED · происхождение канона

По мандату Хозяина от 2026-11-08 мультиагент ПОЛИМАТ произвёл консолидацию Windows-трилогии.

- Канонический репозиторий: **windows-chronicle** (этот).
- Поглощено: `windows-encyclopedia` (20 коммитов), `windows-full-report` (19 коммитов) — оба дублировали тему «Windows 1985–2026: версии, боли пользователей, продвижение Microsoft» с одной датой среза 31.10.2026.
- Полные тела поглощённых сохранены каталогами `merged-from/<имя>/` без изменений содержимого.
- Полные git-истории поглощённых — в `polimat-vault` (bundle + SHA256): восстановление возможно в течение 90 дней средствами GitHub и бессрочно — из бандлов.
- Причина: правило архитектуры «один факт — один канонический репозиторий» (ARCHITECTURE.md, кластер E).
