# Эпоха 2: 1995–2001 — Windows 95/98/Me и NT 4.0/2000

Верифицировано 31.10.2026. Источники: [S2], [S41], [S19], [S39], [S40].

## Вехи

- **24.08.1995 — Windows 95**: запуск с Rolling Stones «Start Me Up» (Microsoft
  лицензировала песню специально), Билл Гейтс и Джей Лено на презентации [S41].
  Маркетинговая кампания оценена примерно в 1 млрд $ [S41]. Появились
  Start-кнопка, панель задач, корзина, ярлыки на рабочем столе, Plug and Play,
  длинные имена файлов, 32-битная вытесняющая многозадачность, стек TCP/IP [S41].
- **24.08.1996 — Windows NT 4.0**: интерфейс 95 на ядре NT.
- **25.06.1998 — Windows 98** (+ SE 10.06.1999): USB, FAT32, интеграция
  Internet Explorer в оболочку.
- **14.09.2000 — Windows Me**: последняя из линии 9x [S2].
- **17.02.2000 — Windows 2000**: NT для бизнеса; Active Directory.
- **Май 2000 — ILOVEYOU**: червь через Outlook Exploit/Windows Script Host,
  45 млн машин за сутки [S39] — первое массовое осознание «Windows + Outlook =
  колея для вирусов».

## С чем боролись пользователи (эпоха 2)

- **Windows Me — репутация катастрофы**: «significant criticism for stability
  problems… one of the worst» (Wikipedia) [S19]; зависания, крахи загрузки,
  проблемы с Real Mode. Классика жанра «лучше 98 SE, не трогайте Me».
- **Синий экран смерти 9x**: случайный BSOD стал культурным символом эпохи.
- **Вирусы и макросы**: ILOVEYOU (2000) — 45 млн машин за 24 часа [S39];
  антивирус становится обязательным бытом.
- **Реестр**: деградация после установки/удаления программ, культ «чистильщиков».
- **Драйверы и конфликты устройств**: PnP работал не всегда; «загадочное
  железо» требовало ручной возни.
- **Фрагментация FAT32**: регулярные дефрагментации как ритуал.

## Что продвигала Microsoft (эпоха 2)

- **Windows 95**: Start-кнопка и PnP — «компьютер, который сам настраивается»;
  мегакампания с музыкой и ТВ [S41].
- **98/Me**: USB и «легкая жизнь» периферии; интеграция веба (IE в оболочку).
- **2000/NT**: Active Directory и корпоративная управляемость.
- DirectX (появился на 95-й платформе) — «лучший гейминг на ПК».
