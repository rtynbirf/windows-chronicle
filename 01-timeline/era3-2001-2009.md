# Эпоха 3: 2001–2009 — Windows XP и Vista

Верифицировано 31.10.2026. Источники: [S2], [S4], [S20], [S22], [S30], [S29].

## Вехи

- **25.10.2001 — Windows XP**: слияние потребительской (9x) и корпоративной
  (NT) линий на ядре NT. 12,5 лет поддержки (до 08.04.2014 [S4]).
- **06.08.2004 — XP SP2**: Security Center, встроенный брандмауэр Windows,
  Data Execution Prevention — крупнейший «пакет безопасности» в истории
  Windows (news.microsoft.com) [S30].
- **2004–2006 — Windows Genuine Advantage (WGA)**: антипиратская проверка.
  04.05.2006 — Microsoft подаёт иски против распространителей нелицензионных
  копий [S22]; 07.07.2006 — жалобы на ложные срабатывания на легальных копиях
  XP [S22]; 06.08.2006 — общественная буря и иски [S22].
- **30.01.2007 — Windows Vista** (бизнес-релиз 30.11.2006): Aero Glass, UAC,
  BitLocker, Sidebar, поиск. **Октябрь 2008 — Windows Vista Capable-скандал**
  (продажа машин с Vista Basic, не тянувшей Aero).
- **Сентябрь 2008 — кампания «I'm a PC»**: ответ на Apple «Get a Mac»,
  300 млн $, агентство Crispin Porter + Bogusky; плюс «Mojave Experiment» —
  показ Vista людям под другим именем [S29].
- **Ноябрь 2008 — Conficker**: червь через сеть/Autorun, миллионы машин [S40].

## С чем боролись пользователи (эпоха 3)

- **Активация и WGA**: «легальные копии признавали пиратскими» (07.07.2006,
  [S22]); уведомления при каждом входе; система проверок воспринималась
  как «шпионская надстройка»; два иска 2006 года, иск отклонён судом 10.02.2010 [S22].
- **Vista — самая критикуемая версия** [S20]:
  - UAC — «security through endless warning dialogs» [S20]; PC Tools (май 2008):
    ~70 % домашних Vista-систем заражены малварью, UAC обвиняли в том,
    что пользователи приучились «жать Да не читая» [S20];
  - требования к железу и слабая база драйверов у релиза; звук/видео/принтеры
    первые месяцы были лотереей;
  - «Vista Capable»: нетбуки и дешёвые машины без Aero.
- **XP — вечный долгожитель**: пользователи держались за XP до 2014; Microsoft
  продлевала EOL, а корпорации (банкоматы, госпитали) оставались на нём годами —
  и это создало почву для WannaCry-2017.
- **Малварь-эпидемии**: Conficker (ноябрь 2008) — миллионы заражений через
  сеть и флешки (Autorun) [S40]; Blaster-поколение червей вынудило MS
  сделать SP2 [S30].

## Что продвигала Microsoft (эпоха 3)

- **XP**: стабильность NT для всех + Luna-интерфейс; « Plug and Play для всех»;
  позже — SP2 как «прорыв в безопасности»: Security Center, брандмауэр, DEP [S30].
- **Vista**: Aero и «эффектный» UI; UAC как щит против малвари; BitLocker
  (шифрование диска) для бизнеса; SuperFetch/ReadyBoost.
- **Маркетинг**: «I'm a PC» и «Mojave Experiment» — Vista «лучше её репутации» [S29].
