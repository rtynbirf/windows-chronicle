# Категория 8: Удаление функций и наследие (2012–2026)

Каждая версия что-то забирает. Хроника потерь (верифицированные случаи).

## 8.1 Классика удалений

| Что удалено | Когда | Контекст |
| --- | --- | --- |
| Меню «Пуск» | 2012 (8) | Возвращено в 10; Start Screen хоронили до 2021 [S37] |
| Windows Media Center | 2015 | Ветеран 2002–2015 |
| Гаджеты рабочего стола | 2012 (8) | Причина — безопасность (после предупр. 2012) |
| Cortana | 2023–2024 | Официальное отключение отдельного приложения; остатки — в Bing |
| WordPad | 2023–2024 | 29 лет в системе; удалён в 24H2 |
| Android-подсистема WSA | 2025 | Анонс 2021 (одна из главных фич 11); поддержка закончена 05.03.2025 |
| Просмотр «Windows Experience Index» | 2015+ | Убран из UI |

## 8.2 Изменение поведения без удаления

- Панель управления → «Параметры»: 10 лет миграции, часть функций
  недоступна из классики (пользователи держат ссылки на applets).
- «Изображение в изображении» старого образца, Windows Photo Viewer —
  замена на приложения Store-типа.
- Charms (2012) → Центр уведомлений (2015) → новый Центр (2021) —
  три поколения за 9 лет.

## 8.3 Наследие и совместимость

- Обратная совместимость Win32 — актив Windows, но и бремя: SMBv1 ради
  старых NAS — дверь WannaCry [S23].
- 16-битные приложения не работают на 64-бит; DOS-игры — через эмуляторы.
- LTSC/IoT-сборки как «тихая гавань» без рекламных фич: Windows 11 IoT
  Enterprise LTSC 2024 — поддержка до 10.10.2034 [S8]; пользователи платят
  удобством ради отсутствия «нового».

## 8.4 WaaS-ритм как источник тревоги

- Полугодовой ритм (10) сменился годовым (11) [S8] — но каждая волна
  обновлений несёт риск «что отнимут в этот раз»: привычки, настройки,
  сторонние инструменты (микрофоны/коды). Опасение потери контроля —
  фоновое состояние пользователя с 2015 года.
