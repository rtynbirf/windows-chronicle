# 04. Боли пользователей Windows за все годы (полюс 1)

Каждый факт верифицирован (теги → [SOURCES.md](SOURCES.md)). Структура: 12 категорий; внутри — хронологически.

## A. Стабильность и сбои

1. **Прото-BSOD с самого начала (1985–1992).** Уже Windows 1.01/2.03 при неверной версии DOS выдавали экран нечитаемых символов; в 2.0/2.1 формат близок к современному BSOD. Пользователь 1985 года получал «синюю стену» без объяснений [V-050].
2. **BSOD на сцене у Гейтса (20.04.1998, COMDEX/Spring Чикаго).** Демо Plug and Play Windows 98 упало синим экраном при подключении сканера; Гейтс: «Вот почему мы ещё не выпускаем Windows 98»; зал аплодировал [V-051].
3. **Windows ME (2000) — «Mistake Edition».** PC World «The 25 Worst Tech Products of All Time»: 4-е место, пользователи жаловались на установку, работу, совместимость [V-052].
4. **1809 удалял файлы (окт. 2018).** October 2018 Update стирал документы пользователей; Microsoft остановила развёртывание (ZDNet, 10.10.2018; Computerworld, 06.10.2018) [V-053].
5. **CrowdStrike-каскад (19.07.2024).** ~8,5 млн устройств Windows (<1%) — официальная оценка Microsoft (блог Дэвида Уэстона); парализованы рейсы, больницы, банки по всему миру [V-054].

## B. Обновления и жизненный цикл

1. **Форс-апгрейды GWX (2015–2016).** Навязчивые попапы «Get Windows 10»; в мае 2016 окно записывало ПК на апгрейд даже при закрытии крестиком (PCWorld «…deceives you into upgrading», 22.05.2016; ExtremeTech: «клик по X не отменяет установку», 23.05.2016) [V-055].
2. **Вердикт Голдстайн (сообщения 25–28.06.2016).** Суд присудил ~$10 000 за принудительный апгрейд, сломавший компьютер; Guardian/BBC/Computerworld. Пометка: факт выплаты верифицирован заголовками; «отказ от апелляции» — UNVERIFIED [V-056].
3. **Форс-перезагрузки и «активные часы».** Годы перезагрузок без спроса; «Active Hours» пришли только с Anniversary Update (релиз 02.08.2016) [V-057].
4. **Полноэкранные баннеры EOL (2024–2025).** Windows 10 подавала фуллскрин-призывы «обновись/ESU» (windowslatest 03.06.2024; The Register 21.11.2024; XDA 24.08.2025) [V-058].
5. **Конец поддержки как выкручивание рук (14.10.2025).** EOL Win10 при том, что на неё ещё >40% устройств (SecurityWeek, 14.10.2025); потребительская ESU $30/год (анонс 31.10.2024); в июне 2025 добавлены бесплатные пути (синхронизация Windows Backup / 1000 баллов Rewards); 25.06.2026 ESU продлена до 12.10.2027 [V-023, V-044, V-045, V-046, V-059].

## C. Приватность и данные

1. **Телеметрия Win10 (2015).** Сбор идентифицируемых данных даже при «минимальных» настройках (The Guardian, 13.08.2015); детальные пояснения Microsoft — только к апрелю 2017 (Ars Technica, 05.04.2017) [V-060].
2. **WGA «phoning home» (2006).** «Антипиратский» уведомитель звонил домой ежедневно; после разоблачений снизили до раза в две недели; класс-акция по анти-шпионским законам (Seattle P-I, 29.06.2006) [V-061].
3. **Люди слушают Cortana/Skype (07.08.2019).** Подрядчики Microsoft прослушивали записи — The Verge [V-062].
4. **Recall-скандал (2024).** Анонс 20.05.2024 на Build → «screenshots everything» назван security-«disaster» (The Verge, 03.06.2024) → 07.06.2024 смягчение до opt-in → 13.06.2024 отложен за день до старта Copilot+ → вторая задержка 31.10.2024 → превью 06.12.2024 (opt-in, Windows Hello, шифрование) → постепенный релиз с 04.2025 [V-063].

## D. Реклама и навязывание сервисов

1. **Реклама в Solitaire (2015, фактически с 2014-го в Win8-эпоху — точный старт UNVERIFIED).** Microsoft Solitaire Collection показывала рекламу; отключение — $1,49/мес (Business Insider, 27.07.2015); «Windows 10 has completely ruined Solitaire» (The Independent, 30.07.2015) [V-064].
2. **Реклама на экране блокировки (2016).** Windows Spotlight-промо; гайды «как убрать навязчивую рекламу» (TechSpot 25.02.2016; Windows Central 09.11.2016) [V-065].
3. **Реклама Microsoft 365 в Проводнике (тест с 03.2022).** «Microsoft accidentally reveals it is testing ads in Windows Explorer» (Ars Technica, 16.03.2022) [V-066].
4. **Реклама в меню «Пуск» (04.2024).** Тест промо-карточек в секции recommended (BleepingComputer, 12.04.2024), затем раскатка на всех (PCMag/PCWorld/Tom's Hardware, 24.04.2024); в августе 2024 промо M365 дошли и до Пуска Win10 (gHacks, 26.08.2024) [V-067].
5. **Каталог приёмов в пользу Edge/Bing (верифицировано 01.01.2026).** The Verge: «Every trick Microsoft pulled to make you browse Edge instead of Chrome»; в августе 2026 Microsoft официально подтвердила, что продвигает Edge/Teams/Copilot средствами Windows 11 (windowslatest) [V-068].
6. **OneDrive перехватывал папки (25.06.2024).** Folder Backup включался автоматически; часть решений тихо откатили (Thurrott, 04.07.2024) [V-069].
7. **Признание «проблемы рекламы» (03–22.03.2026).** «Microsoft finally admits Windows has an ad problem» (ynetnews, 05.03.2026); обещание «спокойнее ОС с меньшим числом апсейлов» (windowslatest, 22.03.2026) [V-070].

## E. Лицензирование и учётные записи

1. **Product Activation (2001).** Впервые глобально в Windows XP/Office XP: «купил — но должен просить разрешения»; отказы реактивации на апгрейднутом железе [V-071].
2. **WGA-ложные срабатывания (2006–2007).** 05.10.2006 сбой флагал легальные копии как пиратские; по Ars Technica ~22% из 500 млн ПК «провалили» проверку, из них <0,5% реально пиратские; 25.08.2007 сбой серверов пометил легальные XP/Vista (Microsoft: «<12 000 машин») [V-061].
3. **Обязательная учётная запись Microsoft.** Home — с Win11 (анонс 08.07.2021, How-To Geek); Pro — с 22H2 (анонс 17–18.02.2022, Ars Technica) — заметка: изменение датировано февралём 2022, не 2025-м; обходы (bypass-скрипты) закрывались волнами 31.03.2025 и 07.10.2025 (ZDNet/Ars/Register/BleepingComputer) [V-072].

## F. Совместимость и драйверы

1. **«Plug and Pray» (1995–2000).** Ненадёжный PnP Win95, ISA-конфликты IRQ (линии 3/4/5/7/9) — кличка закрепилась в прессе [V-073].
2. **Подпись драйверов x64 (2007).** Vista x64 требует подписи всех новых kernel-mode драйверов; старое железо без новых драйверов умирало [V-074].
3. **DLL hell (1990-е).** Установка новой программы ломала старую; «зонтичный термин» проблем DLL [V-075].
4. **Реестр и «чистильщики» (1990-е–2000-е).** Большой реестр замедлял 9x; лавина registry cleaners (включая scareware) кормилась страхом [V-076].

## G. Требования к железу

1. **«Windows Vista Capable» (2006–2008).** Класс-акция: XP-ноутбуки с наклейкой «Capable» тянули лишь Home Basic; февраль 2008 — статус class action; документы выявили правки под Intel-чипсеты [V-077]. Пометка: суммы соглашения (Intel $200M / Microsoft $39,4M, ~2021) — UNVERIFIED, сам иск верифицирован.
2. **TPM 2.0 и отсечение железа (2021).** Win11 требует TPM 2.0 + UEFI Secure Boot (официальная страница спецификаций); скан Lansweeper: ~55% рабочих станций не проходили минимальные требования (ZDNet, 12.10.2022); пресса писала о сотнях миллионов рабочих ПК «в сторону э-свалки» (thecooldown, 22.08.2026) [V-078].

## H. Интерфейс и UX

1. **Удаление «Пуска» (26.10.2012).** Впервые с 1995-го; UI «широко раскритикован как запутанный и неинтуитивный»; менеджер Chaitanya Sareen: десктоп теперь «приложение» [V-079].
2. **Миллионы вернули «Пуск» вручную.** Classic Shell — 4,3 млн загрузок с запуска Win8 (Neowin, 11.05.2013) [V-080].
3. **Частичный откат (17.10.2013).** 8.1 вернула видимую кнопку «Пуск» — но не полноценное меню [V-081].
4. **Bloatware (2000-е — наши дни).** OEM-триалы и тулбары как систематическая практика; «Debloat»-гайды — постоянный жанр (PCMag, 25.01.2024) [V-082].

## I. Безопасность как бремя

1. **Melissa (26.03.1999).** Макровирус; ФБР оценило ущерб $80 млн; арест автора менее чем за неделю [V-083].
2. **ILOVEYOU (май 2000).** Червь «создал всемирный хаос» (The Guardian, 05.05.2000); ущерб по поздним оценкам ~US$10 млрд [V-084].
3. **Blaster (авг. 2003).** RPC DCOM-червь для XP/2000; атаковал windowsupdate.com; вечные перезагрузки [V-085].
4. **Sasser (апр.–май 2004).** Падение LSASS = таймер выключения; пострадали AFP и Delta (отмены рейсов) [V-086].
5. **Conficker (2008–2009).** 10–15 млн заражённых машин; годы страха перед «спящей» бот-сетью [V-087].
6. **UAC «far too chatty» (2006–2007).** Ещё до релиза аналитик Yankee Group: «слишком болтлив и раздражающ»; годы дзен-щелчков «Да/Нет» [V-088].
7. **WannaCry-контекст (май 2017)** — упомянут в прессе как итог эпохи незакрытых патчей; отдельная верификация числа машин в этой работе не проводилась (см. UNVERIFIED).
8. **Bing в поиске «Пуска»** — веб-результаты Bing вплетались в локальный поиск; ЕЭЗ-открепление — март 2024 (DMA); глобальный «выключатель» Bing — 23.06.2026 (Windows Central) [V-089].

## Сводка сопротивления пользователей (как именно боролись)

- **Утилиты возврата/обхода:** Classic Shell (4,3 млн загрузок), bypass-скрипты MSA, Rufus-обходы TPM, деблоатеры.
- **Суды:** класс-акция «Vista Capable» (2008), WGA-«spyware»-иск (2006), вердикт Голдстайн (2016).
- **Регуляторы:** DMA в ЕЭЗ — с 13.03.2024 Windows 11 в Европе без Bing-навязывания, с экранами выбора и возможностью открепить Edge/Copilot (блог Windows 16.11.2023; laptopmag 13.03.2024) [V-090].
- **Миграция/игнор:** каждая волна навязывания фиксировалась прессой как топливо для «а не попробовать ли Mac/Linux» (зафиксировано как риторика статей; количественные оценки миграции — вне этой работы).
