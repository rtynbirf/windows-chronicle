# Эпоха 6: 2021–2026 — Windows 11 и ИИ-поворот

Верифицировано 31.10.2026. Источники: [S5]–[S11], [S16]–[S18], [S25]–[S27], [S31], [S32], [S35], [S36], [S42].

## Вехи

- **24.06.2021 — анонс Windows 11** (news.microsoft.com «Introducing Windows
  11») [S32]; «новая эра ПК» — Наделла. **05.10.2021 — общий доступ** [S2].
- **Требования**: 1 ГГц/2 ядра, 4 ГБ ОЗУ, 64 ГБ, UEFI с Secure Boot,
  **TPM 2.0** — официальный минимум Microsoft [S31]. Миллионы машин с Windows 10
  формально «не проходят». Ноябрь 2025: TechPowerUp сообщил о послаблении
  установочных проверок TPM («TPM 2.0 Not Needed Anymore») [S35].
- **03.05.2024 — меморандум Наделлы «Prioritizing security above all else»**:
  безопасность объявлена высшим приоритетом компании [S42].
- **20.05.2024 — Copilot+ PC**: анонс blogs.microsoft.com; требования:
  NPU ≥ **40 TOPS**, 16 ГБ ОЗУ, 256 ГБ SSD; первые машины — Snapdragon X
  Elite/Plus [S25], [S26].
- **Recall-шторм 2024**: функция «скриншотит всё» вызвала шквал критики
  приватности; **13.06.2024** Microsoft отложила Recall до Insider-сборок
  (декабрь 2024) [S18].
- **16.10.2025 — Copilot Vision GA + Copilot Actions**: ИИ «видит» экран,
  агент выполняет многошаговые задачи, «Hey Copilot» [S27].
- **Июль 2026 — Наделла признаёт «rough 2025»**: обещание «quality update»
  и работы над «фундаментами» Windows 11 (windowslatest) [S36].
- **29.09.2026 — Windows 11 26H2 GA** — текущая версия (сборка 26300.9818,
  обновление 28.10.2026) [S8], [S9].

## С чем боролись пользователи (эпоха 6)

- **Железный барьер**: TPM 2.0/Secure Boot и список CPU отсекли годные машины [S31];
  хайп вокруг «обходов установки»; ноутбуки без поддержки — «выброшенные».
- **Обязательная учётная запись Microsoft**: Home — с релиза 2021 [S16];
  обходы через `oobe\bypassnro` и отсоединение сети; в 2024–2026 Microsoft
  последовательно закрывает лазейки; Pro тоже подтянули.
- **Реклама в системе**: с апреля 2024 — «рекомендации» (по сути реклама)
  в меню «Пуск» с официальным тумблером «Show recommendations for tips,
  shortcuts, new apps and more» [S17]; всплывающие уведомления-реклама
  (Microsoft Q&A: «как отключить рекламу в Windows 11», февраль 2026) [S17].
- **Recall**: «функция делает скриншот всего, что вы видели» — буря 2024,
  задержка релиза [S18].
- **Качество обновлений**: 24H2 — блокировки на устройствах Asus (BIOS-фикс),
  проблемы HDD >8 ТБ, BSOD-эпизоды [S8]; признание Наделлы в 2026 [S36].
- **Правый клик и «показать больше параметров»**: новое контекстное меню
  11-й версии — вечный источник раздражения (доп. клик).
- **Навязывание Edge/OneDrive/Copilot**: иконки и баннеры после обновлений,
  Copilot-кнопка на панели задач [S27].

## Что продвигала Microsoft (эпоха 6)

- **«Безопасность по умолчанию»**: TPM 2.0/Secure Boot как фундамент [S31];
  меморандум «security above all else» [S42].
- **Copilot везде**: Copilot+ PC (NPU 40+ TOPS) [S25], Copilot Vision, Actions,
  агенты [S27] — ОС превращается в ИИ-платформу.
- **Лучший гейминг**: Auto HDR, DirectStorage, «the best Windows ever for
  gaming» (заголовок анонса 2021) [S32].
- **WSL/открытость разработчикам**: WSLg (Build 2021), open-source WSL [S28].
- **Ритм «год — версия»**: 24H2 → 25H2 → 26H1 (только новые устройства) → 26H2 [S8].
