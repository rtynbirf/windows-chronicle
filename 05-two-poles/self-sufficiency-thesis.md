# Система самодостаточна: что реально нужно обновлять в Windows

**Тезис, зафиксированный в постановке задачи (31.10.2026):** система = организм. Сердце, печень, почка самодостаточны — они не «обновляются», они работают. Так и Windows: NT-ядро, Win32, NTFS, драйверная модель — самодостаточны. Вопрос «что ты там обновлять собрался?» — главный аргумент против рекламной конструкции «Windows как услуга».

Этот файл — разбор оси №1 рейтинга (`two-poles-ranking.md`, пункт 1): почему «обновления» в трактовке Microsoft не являются жизнедеятельностью системы и что в них действительно необходимо.

---

## 1. Доказательство самодостаточности

| Факт | Даты | Что доказывает |
|---|---|---|
| Windows XP: жизнь без «фич» | 25.10.2001 → 08.04.2014 (12,4 года поддержки) | Система полноценно работала на миллионах машин годами без единого функционального обновления |
| Windows 7: жива до сих пор | 22.10.2009 → 14.01.2020 (EOL) → н.в. (<1 % парка, StatCounter 02.2026) | Шесть лет после конца поддержки — без патчей и фичапдейтов — ядро, NTFS, сеть, печать, игры работают |
| Автономная установка | все версии до Win11 | Ни один фичапдейт не нужен для работоспособности; всё критичное для жизни (драйверы) даёт вендор железа, а не Windows Update |

**Вывод:** за 41 год не появилось ни одного функционального обновления, без которого система перестала бы работать. Фичапдейты — маркетинговые волны, не метаболизм. Орган не спрашивает разрешения, чтобы биться.

## 2. Цепь GWX → 1809 → 24H2: канал контроля, а не услуга

Три витка одного канала. Формулировка на входе — «услуга / безопасность / новые возможности», результат на выходе — принудительная доставка и удар по данным или железу.

### GWX (2015–2016): навязывание
- KB3035583, иконка «Get Windows 10» с «резервированием» апгрейда; после скрытия обновление возвращалось на машину.
- Весна 2016: апгрейд переведён в категорию «рекомендуемых обновлений» — то есть автоустановка у всех, у кого они включены (публикации 05.05.2016 и 23.05.2016, AskWoody / How-To Geek).
- Иск Тери Голдштейн (несанкционированный апгрейд сломал рабочий компьютер): присуждено **$10 000**, Microsoft начала апелляцию и отозвала её (июнь 2016, Ars Technica).

### 1809 «October 2018 Update»: потеря данных
- Релиз 02.10.2018; 03–04.10 — первые отчёты об удалении содержимого «Документов»/«Изображений» (в том числе отчёт о потере 220 ГБ — 23 года файлов, Microsoft Q&A).
- Причина (блог Джона Кейбла, 09.10.2018): удаление «старых» известных папок при Known Folder Redirection.
- Отозвана вся ветка, включая Windows Server 2019; официальная оценка масштаба — «0,01 % установок» (счёт — на тысячи машин); возврат — 13.11.2018.

### 24H2 (2024–2025): отвал железа
- Релиз 01.10.2024; блок установки на ПК с играми Ubisoft (Assassin's Creed Valhalla, Star Wars Outlaws) — 25.11.2024 (BleepingComputer).
- Блоки совместимости вокруг ПО Western Digital и сообщения об исчезновении HDD на платах ASUS (октябрь 2024); BSOD Easy Anti-Cheat; список known issues Microsoft рос весь год.

**Общий знаменатель:** каждый виток — принудительная доставка через тот же канал, которым идут патчи безопасности. Отказаться от «услуги» нельзя, не отключив патчи. Это и есть механизм контроля.

## 3. Честный разбор: что в «обновлениях» действительно нужно

| Категория | Нужна ли системе | Комментарий |
|---|---|---|
| Патчи безопасности | Да — единственная категория | Но: Patch Tuesday (октябрь 2003) создан как ответ на Blaster; WannaCry (12.05.2017, 200 000+ машин) прошёл через дыру SMBv1, патч MS17-010 вышел за месяц до взрыва. Патчи чинят собственные дыры платформы — обслуживание самовоспроизводимого техдолга, не «услуга» |
| Драйверы | Да, но источник — вендор железа | Windows Update — только шина доставки; Microsoft не знает о половине периферии |
| Фичапдейты / enablement-пакеты | Нет | Ни один не был необходим для работоспособности |
| Insider-каналы, Copilot/Recall, реклама, эксперименты | Нет | Контур управления: телеметрия (DiagTrack), смена дефолтов, MSA-гейты, монетизация. Октябрьский Patch Tuesday 2026 закрывает 1414 позиций каталога Qualys (78 критических) — конвейер патчей растёт вместе с поверхностью «услуги» |

## 4. Итог по оси «услуга ↔ контроль»

1. «Обновлять нечего» — доказуемо: базовая система (ядро + Win32 + NTFS + драйверная модель) самодостаточна; ноль фичапдейтов были необходимы для жизни системы.
2. «Услуга» — маркетинговое имя канала управления парком железа: телеметрия, гейты, смена дефолтов, монетизация.
3. «Контроль» — реальный опыт пользователя: навязывание (GWX) → потеря данных (1809) → отвал железа (24H2) → аппаратная стена (TPM 2.0) → кирпич EOL (14.10.2025) → подписка на право продолжать пользоваться купленным (ESU).
4. Единственное, что действительно стоит доставлять, — патчи уязвимостей самой Windows; и даже они приходят через тот же канал, с телеметрией и принудительной перезагрузкой.
