# Эпоха 4: 2009–2015 — Windows 7, 8, 8.1

Верифицировано 31.10.2026. Источники: [S2], [S4], [S37], [S38].

## Вехи

- **22.10.2009 — Windows 7**: курс «исправить то, что раздражало в Vista»:
  легче, быстрее, UAC смягчён. Aero Snap, библиотеки, jump lists, HomeGroup.
  До сих пор считается эталоном «спокойного» релиза.
- **26.10.2012 — Windows 8**: тач-первая платформа: Start Screen (Metro),
  плитки, Charms, магазин Windows Store, платформа UWP/WinRT.
  Классическое меню «Пуск» удалено.
- **17.10.2013 — Windows 8.1**: возврат Start-кнопки (но не полного меню) [S38],
  загрузка сразу на рабочий стол (настраиваемо), улучшенный поиск.
- **09.10.2014 — «почему нет Windows 9»**: основная техническая причина,
  озвученная прессой — код совместимости старых приложений, проверяющих
  имя ОС «Windows 9*» (95/98) [S21].

## С чем боролись пользователи (эпоха 4)

- **Windows 8 — культурный шок интерфейса** [S37]:
  - удалённое меню «Пуск» — «без сомнения один из самых спорных вопросов
    Windows 8» (ghacks) [S37];
  - две среды (рабочий стол и Start Screen) — путаница «где я» [S37];
  - Charms-бары и горячие углы на десктопе без тача — раздражение;
  - волна сторонних решений: Classic Shell, Start8, Pokki — «скачаны миллионами» [S37].
- **Vista-наследие репутации**: «операционка с плохой репутацией, как Vista»
  — типовая формулировка прессы о 8.1 [S37].
- **Обновление 7→8 и обратно**: миграция ломала привычки десяти лет.
- **Устаревание 8 без 8.1 Update**: Store-приложения на десктопе без мыши
  — «половинчатость».

## Что продвигала Microsoft (эпоха 4)

- **Windows 7**: «стабильность и скорость»; Aero Snap/библиотеки — мелкие,
  но точные удобства; маркетинг «I'm a PC and Windows 7 was my idea» [S29].
- **Windows 8**: ставка на сенсорные экраны и планшеты; Windows Store как
  ответ на App Store; UWP — «одно приложение для всех экранов».
- **8.1**: признание ошибки — возврат кнопки [S38]; реклама «примирения».
