# Категория 5: Смена интерфейса, ломка привычек (2012–2026)

## 5.1 Windows 8: удаление меню «Пуск» (2012)

- «The missing start menu is without doubt one of the most controversial
  topics…» (ghacks, 2013) [S37].
- Две среды (Start Screen + рабочий стол) — «где я нахожусь» дезориентация [S37].
- Charms/горячие углы без тача — механика, навязанная планшетной парадигмой.
- Волна сторонних ответов: Classic Shell, Start8, Pokki — «millions of
  downloads» [S37].
- 8.1 (17.10.2013): возврат кнопки, но не меню [S38]; полное меню вернулось
  только в Windows 10.

## 5.2 Windows 10: плитки в Пуске, Cortana в поиске

- Живые плитки и поиск, приписанный к Bing/Cortana — «нельзя выключить»
  (типовая жалоба 2015–2018); решения — через реестр/групповые политики.

## 5.3 Windows 11: центрирование и «упрощения»

- Центрированный Пуск, круглые углы, «Show more options» в контекстном меню —
  вечный допклик; решения: Shift+F10-сразу-реестр, сторонние тулкиты.
- Панель задач: нельзя перетащить/сгруппировать как раньше; часы — только
  на одном мониторе (до 23H2).
- Меню «Пуск»: секция «Рекомендуем» занята промо-контентом (см. категорию 7) [S17].

## 5.4 Урок эпохи

- Модель повторяется: радикальный редизайн (8) → откат (8.1/10) → снова
  редизайн (11) → точечные откаты. Пользователи борются сторонними
  оболочками (Classic Shell/Open-Shell, StartAllBack, ExplorerPatcher) —
  экосистема «верните как было» существует с 2012 года непрерывно.
