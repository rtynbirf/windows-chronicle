# 07. Три прототипа архитектуры «с нуля» (экстраполяция 41 года опыта)

> Мысленный эксперимент: сегодня, глядя на пройденный путь целиком (1985–2026), спроектировать три архитектуры: **A** — радикальный отрицательный полюс, **B** — радикальный положительный полюс, **C** — золотая середина. Входные данные — каталог болей (`03-user-pains/`) и рейтинг конфликтов (`05-two-poles/`).

## 0. Десять законов, выведенных из истории (входные аксиомы)

1. **Закон обновления.** Патч никогда не ломает работающее. Источники: GWX (2015–16), 1809 удалял файлы (2018), KB5063878 и NVMe (2025), WinRE без клавиатуры (2025). → атомарность, откат, изоляция канарейками.
2. **Закон сети.** Сеть — усилитель, не условие. Источник: Блокнот не запускался из-за серверного сервиса (2026). → полный офлайн-режим базовых функций.
3. **Закон единства.** Одна модель настроек, путей, прав, поиска. Источники: Control Panel vs Settings, 260 символов пути, дефолты сбрасывались годами.
4. **Закон совместимости.** Легаси живёт в виртуализации эр, не в ядре. Источники: 16/32/64-битные разрывы, WinSxS, DLL hell.
5. **Закон безопасности.** Безопасность — архитектура, а не nagging. Источники: UAC-спам (2007), VBS-просадки FPS, Recall как приватный сканер.
6. **Закон драйвера.** Ядро не доверяет никому. Источник: хроническая боль №9 за 40 лет.
7. **Закон отзыва.** Глобальный каскад от одного дефектного файла недопустим. Источник: CrowdStrike 19.07.2024 — 8,5 млн машин.
8. **Закон владения.** Пользователь держит ключи и копию. Источники: MSA-обязаловка (2021/2025), удаление bypassnro (2025), ESU-квест (2025–26).
9. **Закон рекламы.** Ядро ОС — не рекламная площадка. Источники: Candy Crush (2015) → спонсорский Пуск (2025).
10. **Закон выхода.** У пользователя всегда есть описанная стратегия ухода с данными. Источник: мобильная эпопея (1996–2019), обесценившая всё.

## A. Полюс «−»: HELIOS — ОС как коммунальная служба

**Манифест:** «Компьютер — терминал, вычисление — услуга, владение — устаревшее слово». Это логическое завершение вектора, который платформа строит с 2012 года: MSA → OneDrive → Store → Copilot → «Локальное состояние — баг, а не фича».

**Стек:**
- **Ядро:** сертифицированный микроядро-гипервизор в защищённом анклаве терминала; сторонний код в ядро не попадает никогда — в принципе.
- **Драйверы:** только подписанные HAL-драйверы тонкого клиента; всё остальное — user-mode + виртуализация устройств на стороне фермы вендора.
- **Приложения:** только модули (WASM-подобные) из единого каталога; права — capability-токены; файловой системы нет — есть объектное хранилище с ссылочной целостностью.
- **Совместимость:** все эры (16-bit, win32, .NET) крутятся в изолированных ферменных VM в облаке; локально нет ни байта легаси.
- **Обновления:** непрерывные, невидимые; понятия «версия у пользователя» не существует — всегда та, что выкатил вендор.
- **Личность и данные:** облачная биометрическая личность; данные в шифрованном облаке, ключи — у вендора (HSM); локальный кэш одноразовый.
- **AI:** только облачные модели, NPU не нужен — стена Copilot+ снимается тем, что железо вообще не решает.
- **Экономика:** подписка за пользователя; бесплатный тариф — рекламный; телеметрия полная.

**Чинит:** BSOD (микроядро), драйверный ад (драйверов нет), поломки обновлений (локальных обновлений нет), пиратство (нечего копировать), вредоносы (нечего исполнять локально), e-waste (терминалы живут 15 лет).

**Создаёт заново — но навсегда:** офлайн = кирпич; сбой вендора = вечный CrowdStrike (Блокнот-2026 — пролог в миниатюре); приватность = 0; владение = 0; отзыв лицензии = потеря всей цифровой жизни; латентность и цифровое неравенство; цена — пожизненная подписка.

**Вердикт:** инженерно самый чистый дизайн из трёх; политически — тупик. «Отрицательный» он потому, что все 25 конфликтов рейтинга здесь решаются отбором прав у пользователя, а не их возвратом.

## B. Полюс «+»: SOVEREIGN — ОС полного суверенитета

**Манифест:** «Корень доверия — ключ пользователя; сеть — опция; машина — суверенная территория». Радикальное обращение каждого вектора платформы.

**Стек:**
- **Ядро:** формально верифицируемое микроядро (класс seL4) + драйверы в user-mode с capability-токенами; ядро малое, аудируемое, стабильное десятилетиями.
- **Доверие:** неизменяемый подписанный образ + декларативный манифест userland; корень цепочки доверия — **ключ пользователя**, не вендора; самосборка и форк — первоклассные сценарии.
- **ФС:** copy-on-write, контент-адресация, снапшоты всего по умолчанию; приложение по умолчанию не видит диск — только выданные файловые capability (конец «приложение читает всё»).
- **ABI:** «ABI-конституция» — один публичный, версионированный, замороженный контракт; совместимость эр — через встроенные VM-«капсулы времени» (16-bit, win32, .NET, web): легаси живёт в песочнице, а не раздувает ядро (закон №4).
- **Пакеты:** универсальный декларативный формат; магазин — опция; sideload и сборка из исходников равноправны.
- **Обновления:** только по решению пользователя; атомарно; откат — всегда в один клик; userland патчится live, ядро — в выбранные пользователем окна.
- **Личность:** локальная; для внешних сервисов — псевдонимы; глобального аккаунта не существует.
- **Телеметрия:** ноль по умолчанию; включение — только с локальным журналом «что и куда ушло», видимым пользователю.
- **AI:** только локальные модели как сменные подписанные пакеты; облачные вызовы отсутствуют в принципе.
- **UI:** один детерминированный shell; единый реестр настроек с версионной схемой (закон №3) — Control Panel vs Settings невозможно by design.
- **Экономика:** вечная лицензия + опциональная техподдержка; реклама запрещена везде и всегда.

**Чинит:** практически весь каталог из 18 категорий болей — напрямую, без компромиссов.

**Создаёт:** вся ответственность на пользователе (безопасность теперь его работа); энтерпрайзу нечем управлять из коробки; выбор парализует новичка; ABI-конституция тормозит фичи; форки фрагментируют экосистему.

**Вердикт:** идеал свободы с ценой зрелости. Положительный полюс: все конфликты решаются передачей прав пользователю — вместе со всеми издержками этих прав.

## C. Золотая середина: SYMBION — двухконтурная ОС

**Манифест:** «Локально — полный суверенитет; в облако — только по явному договору, с выходом в один клик».

**Двухконтурная архитектура:**
- **Контур 1 «Стержень»** = SOVEREIGN-lite: то же микроядро, неизменяемый подписанный образ, COW-ФС, capability-права, стабильная ABI-конституция, локальный корень доверия, локальная личность, эр-VM-совместимость. Работает вечно и офлайн, без облака вообще.
- **Контур 2 «Оркестр»** — опциональные сервисы (синхронизация, бэкап, AI, каталог приложений, управление флотом) поверх **открытой протокольной спецификации**: любой провайдер может реализовать; пользователь меняет провайдера без смены ОС (федерация — закон №10).
- **Криптограница:** Оркестр никогда не держит ключей Стержня; E2E-шифрование; ключи восстановления — у пользователя; escrow — только в хранилище, выбранное самим пользователем.
- **Режимы:** «Дом» (полный суверенитет), «Флот» (энтерпрайз: те же ядра, управление через открытый MDM-протокол, никаких скрытых API для вендора), «Гость».
- **Обновления:** авто-атомарные по умолчанию, всегда с откатом; кольца отсрочки для флота; changelog — первоклассный элемент UI (закон №1).
- **AI:** малые локальные модели работают всегда; большие облачные — только по per-action согласию с записью в аудит-журнал; нет NPU-стены — функции деградируют элегантно вместо отсечения железа.
- **Реклама:** запрещена уставом ниже уровня каталога; спонсорское — только в размеченных секциях каталога приложений.
- **Устав платформы (Platform Charter):** публичный договор вендора — срок поддержки (опубликованный lifecycle, X лет патчей), запрет принудительных аккаунтов, телеметрия только opt-in, право на полный экспорт данных, право на форк (ядро — open-source референс; дистрибутивы вендора — сверху). Соответствие — через независимый аудит и сертификацию.
- **Анти-CrowdStrike-протокол:** сторонний EDR живёт в capability-изоляции; канареечные кольца обязательны; автоматическое стагирование при всплеске аварийных сигналов.

**Чинит:** 25 конфликтов рейтинга прагматично — суверенитет там, где дёшево; облако там, где удобно; выход всегда возможен.

**Создаёт:** сложность двух контуров (настоящая инженерная цена); соблазн вендора «сдвинуть» границу контуров (защита — устав + сертификация + open-core ядро); лёгкое трение UX в местах согласий.

## Эпилог: что прототипы говорят о реальной Windows

- **HELIOS** — куда ведёт текущий вектор при продолжении «как есть»: прологи уже видны (обязательная MSA, Блокнот-2026, Recall, реклама в Пуске).
- **SOVEREIGN** — куда ведёт позиция «пользователь всегда прав»: прологи — культура debloat-скриптов, Rufus-обходы, LTSC-культ, миграции в Linux.
- **SYMBION** — рациональная цель для реальной дорожной карты: неизменяемый локальный стержень, облако как сервис по договору, а не владыка; устав вместо обещаний.
