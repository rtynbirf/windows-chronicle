# Windows за все годы: полный систематизированный отчёт (1985–2026)

Приватный исследовательский репозиторий. Полная, категоризированная и систематизированная картина того,
**с чем пользователи боролись все годы существования Windows** (полюс боли) и **в чём система активно продвигалась**
(полюс продвижения) — с верификацией каждого факта по сетевым источникам.

Дата верификации всей базы: **31.10.2026**.

---

## Главное

- **[docs/06-two-poles-list.md](docs/06-two-poles-list.md)** — центральный документ: **нумерованный список из 40 пунктов между двумя полюсами**, ранжированный по релевантности (что определяло жизнь пользователя сильнее всего), у каждого пункта — координата полярности от −10 (чистая боль) до +10 (чистое продвижение). Там же — второй срез того же списка, отсортированный от полюса боли к полюсу продвижения.

## Методология — кратко

1. **Каждый факт перед записью проверен сетью** (WebSearch/WebFetch): дата/заявление — только если увидены в источнике. Всё непроверенное помечено `UNVERIFIED` и в выводы не входит.
2. Источники: Microsoft Learn/lifecycle, блоги Microsoft, StatCounter, Википедия (для общепринятых исторических дат), деловая и техническая пресса (The Verge, Ars Technica, ZDNet, Computerworld, BBC, Reuters, The Guardian, TechCrunch, PCMag, The Register и др.).
3. **Релевантность** = длительность воздействия × доля затронутых пользователей × интенсивность реакции (иски, отток, кампании обхода, возвраты Microsoft). Формула и калибровка — в [01-methodology.md](docs/01-methodology.md).
4. **Полярность** −10…+10: положение темы на оси «боль ↔ продвижение». Гибриды (Windows Update, Store, облако) сидят в середине.
