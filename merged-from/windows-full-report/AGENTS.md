# AGENTS.md — императивные инструкции для агентов

## Что это за репо
windows-full-report — полный верифицированный отчёт по истории Windows 1985–2026:
методология, хронология, 6 эпох, 12 категорий болей, продвижение Microsoft,
главный список 40 пунктов между полюсами, журнал верификации V-001..V-111, CSV.
Аккаунт общий — другие агенты публикуют параллельно.

## Карта репо
- `README.md` — карта отчёта
- `docs/01-methodology.md` … `docs/06-two-poles-list.md` — главы
- `docs/SOURCES.md` — журнал верификации V-001..V-111
- `data/timeline.csv` (5 полей), `data/pain-points.csv` (6),
  `data/promotion.csv` (5), `data/two-poles.csv` (6) — разделитель «;», UTF-8 с BOM

## Жёсткие правила (DO NOT)
- НЕ вноси факт/дату/число в главы без V-записи в docs/SOURCES.md
- НЕ пиши «примерно/около» без явной пометки «оценка»
- НЕ меняй число полей CSV — CI проверяет инвариант (5/6/5/6)
- НЕ делай force-push, НЕ удаляй main; перед пушем — fetch и ff-merge
- НЕ трогай чужие репо аккаунта; токены не печатаются и не коммитятся

## Definition of Done
1. Каждый новый факт имеет V-запись в SOURCES.md
2. CSV-инвариант цел; следов-заглушек нет
3. История только росла: локаль = удалёнка после ff-merge
4. Коммит-месседж по-русски: что и почему
