# 04. В чём активно продвигают: кампании, лозунги, вечные оси

## 4.1. Продвижение по эпохам

**1985–1990.** Месседж: «графический интерфейс для каждого владельца DOS». В 1986 Балмер в рекламном ролике неистово («high-energy pitch») продаёт Windows 1.0 за $99. Продвигают саму концепцию GUI как способ «не учить команды».

**1990–1995.** Windows 3.0/3.1 продвигают как платформу (не оболочку): TrueType, мультимедиа, звук. Корпоративный месседж NT: надёжность и безопасность класса «главные серверы». С 1994 — легендарный слоган **«Where do you want to go today?»**.

**1995.** Самая дорогая кампания эпохи: ≈$300 млн, Rolling Stones «Start Me Up», подсветка небоскрёба Empire State Building флагом Windows, полуночные продажи. Месседж: «Start — старт новой эры персональных вычислений». Итог: миллионы копий за первые недели, стандарт де-факто за год.

**1996–2000.** NT 4.0/2000 продвигаются через **Windows DNA** (1997) и Active Directory: «Windows — платформа всего корпоративного». Потребительский акцент: интернет из коробки (IE), борьба с Netscape — вплоть до антимонопольного процесса.

**2001–2005.** XP: «Experience», реклама с «Ray of Light» Мадонны; после меморандума **Trustworthy Computing** (январь 2002) — продвижение безопасности как бренда (SP2 презентуется как событие). Параллельно — кампания против пиратства: активация и WGA.

**2006–2011.** Vista: слоган **«The 'Wow' starts now»**; когда реальность разошлась с лозунгом — эксперимент **Mojave Experiment** (2008): «покажем Vista под чужим именем, чтобы люди похвалили». Windows 7: **«Your PC simplified»**, ответная кампания **«I'm a PC»** (сентябрь 2008) против Apple «Get a Mac», «Laptop Hunters» (2009) — «Windows дешевле за те же деньги». Gears of War под «Mad World» — эмоциональный маркетинг.

**2012–2014.** Windows 8: «красивая, быстрая, текучая (fluid)», продвижение Microsoft Store и собственной Surface-линейки; месседж «Windows переизобретена для сенсорных экранов». Скромный результат — источник последующего разворота.

**2015–2021.** Windows 10: **«Windows as a Service»**, бесплатный годовой апгрейд, обещание «последней версии Windows» (формулировка Джерри Никсона, Ignite 2015; Microsoft официально не подтверждала «последней навсегда», но активно ей пользовалась), цель «1 млрд устройств», #DoGreatThings. Параллельные оси: Cortana, Mixed Reality, «Microsoft loves Linux» (WSL, 2016), Windows 10 S (2017) как «безопасная для образования».

**2021–2024.** Windows 11: **« brings you closer to what you love»**, слоган безопасности **«the most secure Windows yet»** (TPM 2.0, Secure Boot, VBS — продвигаются как причина отсечения старого железа), «feel it». Подчёркивается возвращённая свежесть UI, Teams, Widgets, Android-приложения (анонсировано 2021, закрыто 2024–2025 — тихо снято с рекламы).

**2024–2026.** **«Эра AI PC»**: Copilot+ PC (анонс 20.05.2024) с NPU ≥40 TOPS — новая аппаратная категория; Recall, Cocreator, Studio Effects, Copilot Vision, Click to Do продвигаются как «самая умная Windows». Сервер 2025: «hotpatching — меньше ребутов». 26H2 (2026): «Administrator protection» и встроенный Sysmon — снова безопасность. К февралю 2026 маркетинг публично фиксирует «1 млрд пользователей Windows 11» и ускорение миграции после конца Windows 10.

## 4.2. Десять вечных промо-осей (что продвигают «всегда»)

1. **Простота для массового пользователя** — от «не учи команды DOS» до «PC, который просто работает».
2. **Обратная совместимость** — главный козырь против macOS/Linux: «старый софт и устройства продолжат работать» (и одновременно — вечный источник техдолга).
3. **Безопасность по умолчанию** — Trustworthy Computing (2002) → UAC → Defender → TPM/VBS → Administrator protection (2026). Продвигается волнами, каждая волна легитимирует аппаратные требования.
4. **Игры** — DirectX (с 1995) как «лучший API для игр», Game Pass/Auto HDR/DirectStorage (2019+).
5. **Корпоративная управляемость** — AD/GPO → SCCM → Intune/Autopatch; «полярная» инфраструктура как стандарт де-факто.
6. **Экосистема** — Office/Microsoft 365/OneDrive/Teams: Windows как «дверь» в подписки.
7. **Единая платформа приложений** — Win32 → .NET → UWP/Store → Win32+MSIX (возврат после провала UWP).
8. **Производительность** — каждая версия рекламируется «быстрее и легче предыдущей» (Vista и 11 — исключения, где продвигали «безопасность» вместо скорости).
9. **Облако и подписка** — с Win8 (MSA) до Windows 365: «ваши файлы и настройки везде».
10. **AI-повестка (2023–н.в.)** — Copilot, NPU, on-device модели: первая за десятилетия попытка создать новую категорию железа (Copilot+ PC) и новое обязательство «умной» ОС.

## 4.3. Наблюдение о механике продвижения

Microsoft систематически превращает **регуляторные и технические проблемы в маркетинг**: антимонопольное дело → «выбор браузеров» и открытость; критика уязвимостей → Trustworthy Computing и «самая безопасная Windows»; стагнация Win10 → «Windows as a Service»; стагнация Win11 → «continuous innovation + AI». Каждый новый промо-поворот исторически рождается из болей, перечисленных в разделе 03.
