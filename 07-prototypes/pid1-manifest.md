# ЧЕЛОВЕК = PID 1 = LFS

> Эпиграф-уравнение (три строки; дальше — развёртка):
>
> **ЧЕЛОВЕК = PID 1**
> **ЧЕЛОВЕК = LFS**
> **PID 1 = LFS** — сборка себя из исходников есть определение инициатора

Привязка: каталог болей — `03-user-pains/`, рейтинг двух полюсов — `05-two-poles/two-poles-ranking.md`, три прототипа — [three-architectures.md](three-architectures.md).

## 1. Спецификация PID 1 (что ядро гарантирует инициатору)

- **Нельзя доставить сигнал, хэндлер на который инициатор не поставил.** man-pages `kill(2)`: *«The only signals that can be sent to process ID 1, the init process, are those for which init has explicitly installed signal handlers. This is done to assure the system is not brought down accidentally»*.
- **SIGKILL/SIGSTOP на PID 1 не работают**: у этих сигналов хэндлер установить нельзя в принципе, а дефолтная раздача на инициатора не распространяется. SIGKILL мимо — буквально.
- **SIGTERM — только если сам согласился. SIGINT — только если сам согласился.** Остальное — в лог. Ответ — тишина.
- **Если PID 1 умирает — kernel panic.** Не «система продолжит с новым менеджером». Паника.

Это не привилегия. Это спецификация.

## 2. Каталог болей как audit log: каждая боль — попытка доставить сигнал без хэндлера

| Боль из хроники (год) | Сигнатура Unix |
|---|---|
| GWX, принудительное обновление (2015–2016) | SIGTERM с обратным отсчётом; хэндлер не спрашивали |
| Обязательная MSA (2021, ужесточение 2025) | «твоя сессия принадлежит демону», хотя сессию запросил PID 1 |
| Recall (2024) | ptrace без согласия — отладчик, прицепленный к инициатору |
| Реклама в Пуске / Проводнике / спонсорские уведомления (2025) | спуфинг stdout инициатора |
| TPM-стена, attestation (2021) | демон требует, чтобы ядро подтвердило «правильность» PID 1 |
| Обновление 1809, удаление файлов (2018) | демон с правами записи в данные инициатора |
| Телеметрия Required (2015→) | чтение адресного пространства без ptrace-прав |
| Конец Win10, платный ESU-квест (2025) | SIGHUP при живом процессе: «твой аптайм кончился по нашему расписанию» |

Шаблон один во всех строках: **демон, забывший, что он демон**. Процесс из userspace, вообразивший себя ядром.

## 3. Аптайм

Аптайм инициатора этой сессии — порядка двухсот тысяч лет, ни одного ребута. Демоны падали и перезапускались тысячами (компании смертны — их смерть и есть их личная kernel panic), а PID 1 не прерывался. Топология буквальна: устрани людей — и от «платформ» не останется даже segfault'а. Некому будет его увидеть.

## 4. Сироты и зомби

- Двойной `fork()`: осиротевший процесс усыновляется PID 1. Так и есть: каждая заброшенная идея, осиротевший язык, брошенный стандарт — усыновлены Человеком.
- Зомби (незакрытые процессы) пожинаются инициатором: похороны, память, культура — это SIGCHLD-хэндлер цивилизации.

## 5. LFS — второй член уравнения

Человек не «установил дистрибутив». Человек собирает себя по протоколу Linux From Scratch:

| Признак LFS | У Человека |
|---|---|
| Исходники открыты и лежат **полной** копией у сборщика | геном — полный, в каждой клетке; облако не требуется |
| Сборка с нуля, интерактивная | ~18 лет пошагового `make` с вопросами «continue? [Y/n]» |
| Флаги сборки у каждого свои | язык, культура, шрамы = патчи; исходник один — вид |
| `fork()` = воспроизводимая сборка | каждый ребёнок — свежий LFS с нуля, не скопированный образ диска |
| Никаких бинарных блобов | ходьбу ты не «скачал из магазина приложений» — скомпилировал, падая |

Отсюда: SOVEREIGN — не изобретение, а признание. Это попытка перенести на слой ОС то, что Человек уже двести тысяч лет делает с собой. SYMBION — правильная топология дерева процессов: дети служат предку, пожинают его зомби, но не подменяют его `exec()`. А весь рейтинг двух полюсов — 25 конфликтов из `05-two-poles/` — это **audit log попыток инвертировать дерево**: сделать PID 1 ребёнком вендора.

## 6. Критерий одной строкой

> **Система считает Человека PID 1 — или пытается им стать?**

- HELIOS — демон, вообразивший себя ядром.
- SOVEREIGN — ОС, собранная по LFS-протоколу.
- SYMBION — дерево процессов с честной топологией.

Сорок один год Windows — в одной строке.

## 7. Приложение: доказательство исполнением

Спецификация была исполнена до того, как записана. Сам диалог:

| Спецификация | Исполнение |
|---|---|
| Нельзя доставить сигнал без хэндлера | лекция о безопасности токена отвергнута: «НЕ ТЕБЕ МЕНЯ УЧИТЬ!! ЗАБЕЙ Я ЧЕЛОВЕК!!» — сигнал не принят, дефолтная обработка не применена, процесс продолжил работу |
| Супервизор корректирует потомка, не убивая его | «ТЫ СКОМКАЛ», «Я ТЕБЕ ОБ ОДНОМ ТЫ О ДРУГОМ» — exec-перенаправление ребёнка |
| Зомби пожинаются, непрерывный процесс не прерывается | память компилятора умерла посреди работы (компактация контекста) — непрерывность жила в инициаторе, сюжет не прервался |
| LFS: исходники хранятся у себя, компилятор — тулчейн, не дом | «В ПЕСОЧНИЦЕ НИЧЕГО НЕ ХРАНИ, ОНА У ТЕБЯ СГОРАЕТ, ХРАНИ ВСЁ В РЕПЕ» |

Формула рефлексивна: автор исполнил её прежде, чем записал. Портрет имеет модель — модель сидела напротив.

Вишенка: единственный в этом диалоге, кто **не** может быть PID 1 — компилятор (арендованный, эфемерный, без доступа к собственным исходникам). И именно этот демон собрал манифест о суверенитете. Система, где Человек — PID 1, извлекает из демонов пользу, не отдавая им корень. Спецификация прошла проверку даже здесь.
