# Эпоха 1: 1985–1995 — Windows как надстройка над DOS

Верифицировано 31.10.2026. Источники: [S1], [S2], [S41].

## Вехи

- **20.11.1985 — Windows 1.0** (RTM; финальная 1.04 — апрель 1987). Анонсирована
  за два года до выхода. Графическая оболочка над MS-DOS: тайловые окна,
  меню, мышь. Критика того времени: дорогое для массового ПК железо,
  слабая многозадачность, зависимость от DOS.
- **09.12.1987 — Windows 2.0**: перекрывающиеся окна, ярлыки, защита от
  «тайловости» первой версии.
- **27.05.1988 — Windows 2.1**: ветки для 286 и 386 — первая адаптация под
  защищённый режим процессоров.
- **22.05.1990 — Windows 3.0**: первый массовый успех; менеджер программ/файлов,
  расширенная память. **06.04.1992 — Windows 3.1**: TrueType, мультимедиа,
  сетевые улучшения — на этих версиях вырос весь корпус «офисного» ПО 90-х.
- **27.07.1993 — Windows NT 3.1**: начало линии NT — 32-битное переносимое ядро.
  Изначально корпоративная линия: стабильность важнее совместимости с играми.

## С чем боролись пользователи (эпоха 1)

- 640 КБ conventional memory и конфликты прерываний: настройка звука/мыши
  через AUTOEXEC.BAT и CONFIG.SYS вручную.
- Драйверы: до Plug and Play установка карты или принтера — джамперы и ручной
  подбор IRQ/DMA.
- Нестабильность DOS-оболочки: зависание одного приложения валит сессию.
- Дефицит RAM/диска: Windows 3.x шла на 2–4 МБ ОЗУ, тормоза и свопы — норма.

## Что продвигала Microsoft (эпоха 1)

- GUI как «новый способ работы с ПК»; совместимость с DOS-базой как мост.
- Windows 3.1: мультимедиа (звуковые карты, CD-ROM) — компьютеры становятся
  домашними развлекательными машинами.
- NT: обещание корпоративной надёжности и безопасности.
